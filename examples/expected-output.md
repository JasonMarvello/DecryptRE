# Example runs

All ciphertexts in this folder were generated by DecryptRE itself. Commands
assume you are in the repository root and have run `pip install -e .`.

Every result names the method, the recovered parameters, and a plain-language
confidence note. `--verbose` adds the raw score and search depth.

## 1. Caesar cipher (`caesar.txt`)

```bash
decryptre decrypt --input examples/caesar.txt --method caesar --top 2
```

```text
[1] Caesar shift  ·  shift 7  ·  confidence: high
    reads like ordinary English.
    Meet me at the old lighthouse at midnight. Bring the map.

[2] Caesar shift  ·  shift 22  ·  confidence: low
    weak English signal; probably a wrong guess.
    Xppe xp le esp zwo wtrseszfdp le xtoytrse. Mctyr esp xla.
```

Even the unbroken ciphertext is shown, so you can see why the English one
scores higher.

## 3. Layered puzzle (`layered.txt`)

The file is Base64 around a Caesar cipher. Auto mode finds the whole chain:

```bash
decryptre decrypt --input examples/layered.txt
```

```text
No verified result. The guesses below are ranked by English-likeness,
not proof: treat them as suggestions and read them before trusting them.

[1] Base64  ·  one decode layer  ·  confidence: very low
    does not read like English; almost certainly a wrong guess.
    path: Base64
    Wljpcpo afkkwpd lcp qfy: opnzop xp, espy dstqe xp mlnv.
```

## 4. Fernet with a known passphrase (`fernet.txt`)

```bash
decryptre decrypt --input examples/fernet.txt --method fernet --key sunshine
```

```text
[1] Fernet  ·  confidence: verified
    the passphrase was verified by the cipher itself (authentication tag).
    This message was protected with a passphrase from the wordlist.
```

The passphrase is verified by the cipher, so the result is marked high
confidence. Without `--key`, DecryptRE tries the bundled wordlist; that is a
dictionary attack and takes minutes on purpose (the KDF work is the point of
modern encryption). If `sunshine` were not in the list, the command would say
so instead of pretending the cipher can be brute-forced.

## Rebuilding the examples

```python
from decryptre import classical, encodings, modern_crypto

caesar_plain = "Meet me at the old lighthouse at midnight. Bring the map."
open("examples/caesar.txt", "w").write(
    classical.caesar_encrypt(caesar_plain, 7) + "\n"
)

fernet_plain = "This message was protected with a passphrase from the wordlist."
open("examples/fernet.txt", "w").write(
    modern_crypto.encrypt_fernet(fernet_plain, "sunshine") + "\n"
)
```

Every run of AES or Fernet uses fresh random bytes, so the stored ciphertexts
are examples, not fixtures.
